# README assets

`hero.webp` is original AI-generated project artwork, created with the built-in
ImageGen tool. It illustrates a voxel landscape emerging from a silver laptop;
it is not a Minecraft screenshot or a performance claim

`launcher.jpg` is an unaltered screenshot of the locally running native launcher,
captured on October 19, 2026. It contains no account information

The hero is encoded as WebP at quality 82 with metadata removed. Both images
remain below the exporter's 2 MiB limit. Keep new images individually listed in
the source allowlist and give each image meaningful alternative text

## Artwork prompt

Create one polished original editorial hero illustration for the GitHub README
of a project that runs Minecraft Bedrock for Windows on Apple Silicon Macs.
Use-case: stylized-concept. Very wide landscape composition, approximately
2.4:1. A carefully crafted miniature voxel landscape of grass-topped blocks,
stone cliffs, a small waterfall and square-leaf trees emerges from the open
screen of a clean silver Mac-style laptop. Clear recognisable laptop silhouette,
no logos. Ground the laptop on a soft cool-white seamless surface; expansive
pale blue sky and quiet negative space, fresh daylight, natural greens, stone
grey and water blue. Distinct crisp voxel geometry with refined physical
lighting and believable material texture, like a beautiful small architectural
model photographed in a studio. Landscape and laptop form one coherent
composition. No people, mobs or characters. No text, lettering, captions, UI,
menus, fake screenshot, badges, speed claims or branding. It must read as
original project artwork rather than an actual game screenshot. No ornamental
gradients, neon glow, dark dashboard background or generic SaaS elements.
Output a finished lightweight-looking hero image with generous breathing room
around the subject
